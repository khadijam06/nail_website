# Sizing Reference Photos

This folder contains the reference images that show customers how to properly size their nails for ordering.

## Files needed:
- `sizing-1.jpg` - Single finger shot with coin reference
- `sizing-2.jpg` - Two fingers shot with coin reference  
- `sizing-3.jpg` - Full hand reference with coin

## How to add your photos:
1. Copy your sizing reference images to this folder
2. Rename them to match the filenames above (sizing-1.jpg, sizing-2.jpg, sizing-3.jpg)
3. Make sure images are at least 400px wide for best display
4. Images should clearly show fingers with a Qatari coin (dirham) for size comparison

The order.html page will automatically display these images to guide customers on proper sizing.
